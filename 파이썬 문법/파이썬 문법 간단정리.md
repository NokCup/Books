   - strip : 문자열 양옆 공백 제거

### 리스트 요소 추가 : append(), insert(), extend()

- _리스트명.append(요소)_     
: 리스트 뒤에 요소 추가

- _리스트명.insert(위치, 요소)_
: 리스트 원하는 위치에 요소 추가

- _리스트명.extend([요소, 요소, ...])_
: 여러개의 요소를 추가 (append() 확장 )
: 매개변수로 리스트를 입력

```py
list_a = [1, 2, 3]      #리스트 선언

list_a.append(4)        # append()
print(list_a)           # [1, 2, 3, 4]

list_a.insert(2, 7)     # insert()
print(list_a)           # [1, 2, 7, 3, 4]

list_a.extend([5, 6]) #extend()
print(list_a)			# [1, 2, 7, 3, 4, 5, 6]
```
<br><br><br>


## 리스트 연결 연산자와 요소 추가의 차이
- 연산자(+, *) 는 원본(변수)에 변화를 주지 않는다. 
하지만 append(), insert(), extend() 와 같은 요소 추가 함수는 원본(변수)에 
직접적인 영향을 준다. 
그러므로 리스트 연결 연산자와 같이 원본에 영향을 주지 않는 것을 **_비파괴적_** 이라 표현하고 append(), insert(), extend()와 같은 함수를 **_파괴적_**이라고 표현한다

## global
변수는 크게 지역변수와 전역변수로 나뉜다.<br>
지역변수는 함수나 클래스 멤버함수(메소드) 안에서 생성된 변수를 의미하고,<br>
전역변수는 함수, 클래스 외부에서 생성된 변수를 의미한다. <br>
전역변수는 파일 어디든 사용이 가능하나, 지역변수는 변수가 만들어진 함수 내부에서만 사용 가능하다.

```py
def calc_perimeter(radius):
    print("파이값: ", pi)
    perimeter = 2*pi * radius		# global perimeter 사용해야함.

pi = 3.14
perimeter = 0
calc_perimeter(10)
.
.
```

위 코드에서 함수 내부에서 pi와 perimeter가 전역변수로 선언되었다. <br>
calc__perimeter 함수 내부에서 pi는 전역변수 pi와 같지만, perimeter는 아니다. <br>
만약, 전역변수로 선언된 변수를 함수 내에서 '사용'하는 것이 아닌 '변경' 한다면 새로운 지역변수로 생성된 것이다. <br>
지역변수로 사용하려면 함수 내부에서 값을 변경한 변수에 global 키워드를 붙여주자.
