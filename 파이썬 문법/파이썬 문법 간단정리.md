## format() 기능

```py
a = "{:d}".format(10)
# 매개변수로 정수만 가능

b = "{:5d}".format(52)
# 5칸을 빈 칸으로 잡고 뒤에서부터 52를 채움 ( _ _ _ 5 2 )

c = "{:10d}".format(52)
# ( _ _ _ _ _ _ _ _ 5 2 )

d = "{:05d}".format(52)
# 5 칸을 빈 칸으로 잡고 뒤에서부터 52를 채움. 공백을 0으로 채움 (0 0 0 5 2)

e = "{:05d}".format(-52)
# ( - 0 0 5 2 )
```

<Br><Br>

```py
f = "{:+d}".format(15)
#{:+d} 에서 '+' 는 기호표기의 의미
# >>> +15

g = "{:+d}".format(-15)
# >>> -15


h = "{: d}".format(15)
#{: d} 는 함수에 입력한 기호를 따라간다.
# >>> 15

i = "{: d}".format(-15)
# >>> -15
```

<Br><Br>

```py
k = "{:=+5d}".format(-52)
# 5d = 5칸 공백, '+' = 기호표시 , '=' = 기호를 빈칸 앞에 붙임
# >>> - _ _ 5 2
```

## f-문자열
- format() 함수를 간단하게 사용 가능하다.

```py
print("3 + 4 =" + str(3 + 4))       

print("3 + 4 = {}".format(3 + 4))   #format() 이용

print(f"3 + 4 = {3 + 4}")           #f-문자열 이용용
```

<br><br>

일반적으로 f-문자열이 간편하고 좋으나 format() 이 더 편한 경우도 있다.

  1. 문자열 내용이 너무 많을 때
```py
>>> word = "문자"
>>> capital = "대문자자"
>>> """
변수나 함수명 같은 식별자(identifier)의 명칭을 작성할 때 이름을 정의하는 것도 코딩 스타일 중 일부입니다. 대표적인 표기법은 다음 네 가지가 있습니다.

카멜 표기법(Camel Case)
여러 단어를 연달아 사용할 때 각 { }의 첫 글자를 { }로 적되, 맨 앞에 오는 글자는 소문자로 표기하는 것입니다. 낙타의 등에 있는 혹과 같다고 하여 카멜(Camel) 표기법이라고 부릅니다. Java의 권장 표기법입니다.
예) camelVariable, firstName, lastName ...

파스칼 표기법(Pascal Case)
단어의 모든 앞글자를 대문자로 표기합니다. 카멜 표기법이 단봉낙타라면 파스칼은 쌍봉낙타라고 할 수 있습니다
""".format(word, capital)
```

## 다양한 함수와 연산자자

1. `upper()`, `lower()`
   - upper() 은 대문자로, lower() 은 소문자로 바꾼다. 
   - 비파괴 함수

```py
a = 'hello world'
b = 'Hi erIC'
print(a.upper())        # HELLO WORLD
print(b.lower())        # hi eric
``` 

<br>

2. `strip()`
   - strip : 문자열 양옆 공백 제거
   - lstrip() : 문자열 왼쪽 공백 제거
   - rstrip() : 문자열 오른쪽 공백 제거

```py
a = "   반가워요   "
print(a.strip())    #반가워요
print(a.lstrip())   #반가워요 _ _ _
print(a.rstrip())   #_ _ _ 반가워요
```

<br>

3. `find()`, `rfind()`
   - find() 는 문자열 내부에 특정 문자의 위치를 _**왼쪽**_ 부터 찾는다.
   - rfind() 는 _**오른쪽**_ 부터 찾는다.
  
```py
a = "안녕안녕하세요"
print(a.find("안녕"))       # 출력 : 0 (인덱스 번호로 찾는다.)
print(a.rfind("안녕"))      # 출력 : 2
```

<br>

1. in 연산자
   - 문자열 내부에 어떤 문자열이 있는지 확인하는데 사용한다.

```py
print("안녕" in "안녕하세요")   # True
```
