# 연결된 구조

## 연결된 구조 장단점
- 장점
    1. 용량 고정되지 않고 메모리를 효율적으로 사용
    2. 메모리가 남아 있는 한 계속 자료를 넣을 수 있음
    3. 자료 삽입 삭제가 용이함(O(n))
    4. 링크 수를 늘리면 선형 자료구조 뿐 아니라 Tree나 Graph도 표현 가능

- 단점
    1. n번째 요소 접근하는데 O(n)이 걸림
    2. 구현이 어려움
    3. 노드에 데이터와 링크 두 영역이 있음
    4. k번째 자료의 주소를 계산하려면 시작요소에서 링크를 따라 k번째 까지 이동


<br><br>

## Array & Linked Structure의 차이
- 배열 
    1. 데이터를 연속된 공간에 저장
    2. 삽입 삭제 시간복잡도 O(n)
    3. 요소 접근 시간복잡도 O(1)
   
- 링크드 리스트
    1. 데이터가 여기저기 흩어져 있고, 이를 링크로 연결된 선형자료구조
    2. 삽입 삭제 시간복잡도 O(1)
    3. 요소 접근 시간복잡도 O(n)


<br><Br>

## 연결된 구조 용어 정리
- 노드 : 연결된 구조에서의 하나의 Entity
<br><br>

- 노드의 구성 : data 필드와 link 필드

<Br><Br>

- 시작 노드, 헤드포인터
<br>
: 연결된 구조에서는 시작노드만 알면 링크로 모든 노드에 순차적으로 접근할 수 있음.
따라서 시작노드의 주소를 반드시저장해야함
<Br><br>

헤드포인터 -> 시작 노드 -> node2 -> node2 -> 마지막 노드 -> NONE

<Br><Br>

- 연결된 구조의 종류
    1. 단순 연결 구조
    2. 원형 연결 구조
    3. 이중 연결 구조

## 단순 연결 구조 (Linked Stack)
- top : 노드의 시작노드(상단노드)를 가리키는 포인터(헤드포인터)

```py
class Node:
    def __init__(self, elem, link = None):
        self.data = elem
        self.link = link


#스택은 후입선출이므로, 삽입 삭제가 시작노드 앞에서 이루어짐
class LinkedStack:
    def __init__(self):
        self.top = None #노드가 없는 경우 헤드포인터는 None이다.
    
    def isEmpty(self):
        return self.top == None  #헤드포인터가 None이면 공백상태
    
    def isFull(self):
        return False    #포화상태인 경우는 메모리가 없는 경우다.
                        # 즉 의미가 없다.

    def push(self, e):
        n = Node(e) # 새 노드를 만듦
        n.link = self.top #헤드포인터가 가리키던 시작노드를 n이 가리키도록 함.
        self.top = n #헤드포인터가 n(새 시작노드)를 가리키도록 함.

    
    def pop(self):
        if not self.isEmpty(): #포화 상태가 아니라면
            n = self.top    #시작 노드의 다음 노드와 해당노드의 반환을 위해 n에 저장
            self.top = n.link   # 헤드포인터가 다음 노드를 가리키도록 만들기
            return n.data       # pop한 노드의 데이터 리턴
        

    def peek(self):
        if not self.isEmpty():
            return self.top.data    #시작 노드의 데이터 리턴
        
    
    #size는 시작노드를 따라 마지막 노드까지 순회해야 하므로 O(n)의 시간이 걸림.
    def size(self):
        node = self.top
        count = 0
        while(node != None):
            node = node.link    #node값에 node.link를 넣어 다음 노드를 가리키도록..
            count += 1             
        return count


    #스택 내용 출력을 위해 모든 노드 순회 O(n)
    def __str__(self):
        arr = []
        node = self.top
        while (node != None):
            arr.append(node.data)
            node = node.link
        return str(arr)

```

<br><Br>

## size 시간복잡도 O(1)
1. LinkedStack class에서 count = 0 초기화

2. push되면 count += 1, pop은 count -= 1, isEmpty()는 count == 0인지 검사 가능

3. def size()에서는 return size 하면 됨

## 단순 연결 구조 (Linked List)
- 스택과 달리 삽입 삭제가 임의의 위치에서도 가능하다.

- Array List는 배열을 미리 준비해야했지만 Linked List 흩어진 자료들을 링크가 연결하는 구조이므로 헤드포인터면 충분하다.


 <br><Br>

 ```py
 class Node:
    def __init__(self, elem, link = None):
        self.data = elem
        self.link = link


class LinkedList:
    def __init__(self):
        self.head = None

    def isEmpty(self):
        return self.head == None
    def isFull(self):
        return False
    
    #getNode(pos) : 헤드포인터에서 pos번 움직여서 pos위치의 Node를 반환
    def getNode(self, pos):
        if pos < 0: return None
        node = self.top     # pos = 0 -> 그대로 시작 노드(0)가 리턴됨
        while pos > 0 and node != None:
            node = node.link
            pos -= 1
        return node
    
    
    #getNode를 통해 pos 위치의 Node를 찾고 그 node의 데이터를 반화
    def getEntry(self, pos):
        node = self.getNode(pos)
        if node == Node: return None
        else: return node.data


    
    def insert(self, pos, item):
        before = self.getNode(pos - 1)
        if before == None:      #pos = 0 -> getNode(-1) -> return None -> 즉, 시작 노드에 삽입하겠다는 의미
            n = Node(item)
            n.link = self.head
            self.head = n
        else:
            #pos위치의 Node를 생성
            node = Node(item)
            node.link = before.link
            before.link = node
            
    
    def delete(self, pos):
        before = self.getNode(pos - 1)
        if before == None:            # 시작 노드 삭제하는 경우는 헤드 포인터도 변경되어야 한다.
            if self.head is not None: # 빈 노드가 아니라면
                self.head = self.head.link
        else:
            before.link = before.link.link


    def size(self):
        node = self.head
        count = 0
        while (node != None):
            node = node.link
            count += 1
        return count
    
    def __str__(self):
        node = self.head
        arr = []
        while(node != None):
            arr.append(node.data)
            node = node.link
        return str(arr)
 ```
